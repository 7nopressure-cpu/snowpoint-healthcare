# SnowPoint Healthcare - Consultoría Especializada en Servicios de Salud

Sitio web moderno y responsive para SnowPoint Healthcare, desarrollado con Next.js y Tailwind CSS, optimizado para despliegue estático continuo en Vercel vía GitHub sin bases de datos complejas.

## Características Principales

- **Arquitectura Estática Moderna (Next.js 14 + Tailwind CSS):** Rápida, segura y con SEO médico optimizado.
- **Sin Dependencia de Bases de Datos:** Cero configuración de backend o Supabase.
- **Canales de Contacto Directos:**
  - Botón flotante y enlaces directos a WhatsApp con mensaje personalizado.
  - Formulario de contacto directo hacia `info@SnowPointHealthcare.com` (compatible con Web3Forms / Formspree o mailto).
  - Enlaces a redes sociales institucionales (LinkedIn, Facebook, Instagram, YouTube, TikTok, X).
  - Acceso directo y descarga del Brochure Institucional en PDF.
- **Diseño "Clinical Prestige":** Generado con Stitch MCP y estándares UI/UX de alta confianza sanitaria.

## Instrucciones de Despliegue en Vercel

1. Inicializar Git y subir a GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: landing page SnowPoint Healthcare"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/snowpoint-healthcare.git
   git push -u origin main
   ```
2. En [Vercel](https://vercel.com):
   - Importa tu repositorio desde GitHub.
   - Vercel detectará automáticamente Next.js.
   - Haz clic en **Deploy**. ¡Tu sitio estará en vivo en menos de 1 minuto!
